# KernelGuard

## eBPF-Powered Runtime Security Sandbox

KernelGuard is a Linux runtime security monitoring and sandboxing
project designed to monitor and control untrusted Python processes
at the Linux kernel level using eBPF.

## Domain

Systems Programming & Cybersecurity

## Technologies

- Python
- C
- Linux
- eBPF
- BCC
- cgroups
- argparse
- JSON

## Planned Features

- Process execution monitoring
- Network connection monitoring
- File-system write monitoring
- PID filtering
- cgroups integration
- JSON-based security policies
- Runtime alerts
- Active syscall blocking

## Development Roadmap

### Step 1

### Step 2

### Step 3
Policy engine and active enforcement.

### Step 4
CLI, systemd integration, testing and documentation.
